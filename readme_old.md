# また負けちゃったね、南井出さん　企画概要
- ティラノスクリプトで作成する、オリジナルカードゲーム＋ショートストーリー

# キャラクター
## 南井出みなみ（みないでみなみ）
- 高校生、髪型：ポニーテール
- 口癖「あ〜あ、また負けちゃった〜」「お、お願いだから見ないで…(////)」
- よくある対戦型キャラゲーのシステムに取り込まれてしまった模様
- ゲームに負けると罰ゲームを恥ずかしがるが、勝ってるときはシステムの台本に従って余裕顔で主人公を煽る「ざぁこ、ざぁこ」

## 主人公=プレイヤー
- 名前は「ああああ」、冒頭シーンは「なまえをいれてください：ああああ[決定]
- 例によって、立ち絵無し(笑)

# ストーリー
- 【プロローグ】みなみが教室で自習していたら、主人公がやってきて「勝負しよう！」→みなみ「なんで？」と思ったら、机の上に「ゲームシステム台本」が置かれていた。一緒に自習していた友人A（ティラノのアセットを使用）も「用事を思い出した」といなくなってしまう
- 「勝負を引き受ける」という選択肢しか出てこないので、しぶしぶ勝負を始めるみなみ→主人公「麻雀よりは簡単だから安心しろ」
- ゲームに負けると、この手のゲームシステムにありがちな「ヒロインが恥ずかしい目にあうご褒美イベント」が発生する。
- みなみが負けると、システムの都合や主人公の課金不足でイベントが進まない
    - 第一話：イベントシナリオ未実装のため無表情でご褒美イベント開始→主人公「ストップ、俺が見たいはそういうのじゃない」（笑）
    - 第二話：CG屋さん人手不足につきイベントCG未実装→代替イラストとして犬のイラスト表示→みなみ「は、恥ずかしい…」→主人公「かわいかったよ」→みなみ「見ないで…」→主人公「犬がさ」
    - 第三話：イベントサーバーが停止、復旧まで72時間以上→みなみ固まる→イベントをスキップすればゲーム再開可能の選択→主人公「何も見なかったぞ」→みなみ「優しいんだ」→主人公「待ってられるかよ😠」
    - 第四話：特別イベント衣装を見るための課金が足らない→主人公「なんで布地が少ない衣装の方が高いんだよ！」
- 最終話だけ、主人公は「どうせ何も変わらないんだろ」とたかをくくってあくびをするが、ヒロインのポニーテールが解ける演出が発生する
    - 主人公は「おっ」と思うが、「▼INSERT COIN」の表示が出て、所持コインが無くなってTHE END

## ストーリー補足
- 何かと「▼INSERT COIN」〜「▼INSERT COINx100」を求められるため、ゲーム開始時に「ヒジの高さまで100円玉を持っておく」ことが注意喚起されるようにする。

# カードゲームのルール
- 二人対戦、先手後手はランダムで決定
- カードは「〇×△□」の図柄４種類、各５枚で20枚＋ワイルドカード「☆」1枚＋スキップカード「S」2枚の計23枚
- 初期状態：場に三枚のカードが置かれている。ただし三枚とも異なる図柄とする
    - ワイルドカード「☆」は初期状態では置かれないようにする
- 手札は２枚、１枚を場において、三枚のカードの図柄が揃った方が勝ち
    - ワイルドカード「☆」はどの図柄ともそろえることができる
    - スキップカード「S」はいつでも出せる。そのまま手番を渡せる。リーチ状態で手札が2枚とも「S」もありうる諸刃の剣(笑)
- すでに場に出ているカードの同じ図柄同士の上にはカードを置けない
- 図柄が揃わなかったら、１枚を山札から引いて手札に補充して交替
- 山札が無くなったら、補充はしない
- 山札も手札も無くなったらゲーム終了、引き分けとする。
- ゲーム終了後にまた次のゲームを開始する
## ポイント
* リーチ目を作った方がリスクが高くなる。相手の手札を読む戦略がいくらかある
* ワイルドカード「☆」を引いたプレイヤーが圧倒的に有利だけど(ﾟεﾟ)ｷﾆｼﾅｲ!!
## これは余裕があったら！
* この手のゲームにありがちな「インチキツール」をゲーム中一回だけ使える
    - 相手の手札を見る
    - 自分の手番をスキップできる（相手にリーチを作らせる、実装度が楽）→これはスキップカード追加のためナシ
    - 絶対押すなボタン（みなみに怒られる）
